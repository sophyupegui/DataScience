# Wine

This project explores the prediction of wine quality using physicochemical data. It is based on a dataset of red or white wine samples, where each sample is scored by quality on a scale.

In q3: Use dimensionality reduction and clustering to discover natural groupings in wine data and visualize the structure of the dataset.

Techniques:

- PCA (Principal Component Analysis): to reduce dimensionality and visualize data in 2D.
- Clustering: using algorithms like KMeans to identify wine groups based on chemical composition.
- Silhouette score: to evaluate clustering quality.

Dataset: located in `data/wine-clustering.csv`.

Libraries:
- Numpy, Pandas
- Seaborn, Matplotlib
- Scipy
- Scikit-learn, Statsmodels
